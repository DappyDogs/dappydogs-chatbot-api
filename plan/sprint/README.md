# Sprints del proyecto

Esta carpeta ofrece una vista operativa de la planificación por sprint. La fuente canónica del alcance, los criterios de aceptación y el detalle técnico continúa siendo [`plan/epic/`](../epic/).

Los documentos de sprint no duplican las descripciones de EPIC, HU o TASK: únicamente enlazan sus documentos canónicos y reflejan su asignación operativa actual en Milano.

## Criterio de puntos

- `Puntos comprometidos en Milano` reproduce el campo del sprint sin recalcularlo.
- `SP de TASK asignadas` suma las estimaciones de las TASK enlazadas en cada documento.
- Las EPIC y HU no tienen Story Points propios.
- La suma total de las TASK planificadas es de 128 SP: 14 de discovery y 114 del desarrollo posterior.
